# Ruby Examples for BinaryOptionsTools

Example Ruby programs demonstrating the BinaryOptionsTools library with Async fiber support.

## Prerequisites

- Ruby 3.0+
- The generated Ruby bindings (not published to RubyGems — generate them from
  this repository; see [`crates/bindings_uniffi/README.md`](../../../crates/bindings_uniffi/README.md))
- Async gem

```bash
cargo run -p binary_options_tools_uni --bin uniffi-bindgen generate --library --language ruby --out-dir out/ruby
gem install async
```

## Getting Your SSID

Visit [PocketOption](https://pocketoption.com), open DevTools, find `ssid` cookie.

## Running Examples

```bash
ruby basic.rb
ruby balance.rb
```

## Examples

- `basic.rb` - Initialize and get balance
- `balance.rb` - Get account balance
- `buy.rb` - Place buy trade
- `sell.rb` - Place sell trade
- `check_win.rb` - Check trade results
- `subscribe.rb` - Subscribe to real-time data

## Important

```ruby
require 'async'
require 'binary_options_tools_uni'   # module generated by uniffi-bindgen

Async do
  # Ruby exposes new_with_url / new_with_config; there is no plain new(ssid)
  client = PocketOption.new_with_config('your-ssid', ['wss://api-eu.po.market/socket.io/?EIO=4&transport=websocket'], 30)
  puts "Balance: $#{client.balance}"
  client.shutdown
end
```
